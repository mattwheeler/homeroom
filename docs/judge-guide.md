# OpenAI Build Week judge guide

Homeroom is reviewed through the real product paths. There is no separate demo application.

## Access

1. Open the deployed root URL.
2. Expand **OpenAI Build Week judge access**.
3. Enter the private review code supplied in Devpost's non-public testing instructions.
4. Open either **Student view** or **Guardian view**.

The review identity expires after two hours, is rate limited in D1, and resolves to the same fictional Emily/Matt household used in the video. It does not replace or rewrite the verified Google identity records.

## Recommended walkthrough

### Emily — student

1. On **Today**, choose an optional private check-in or start the recommended next step.
2. Open the Task Room, complete a visible step, end the focus session, and confirm it appears in activity history.
3. Review **Calendar**, **Classes**, and source-backed **Supplies**.
4. Open **Learn** and start a short, class-scoped Learning Room.
5. Preview and send a guardian-help note; the exact approved text is the only content shared.

### Matt — guardian

1. Open **Family inbox** and acknowledge Emily's note.
2. Review Emily's progress summary without viewing private coaching dialogue or answers.
3. Review age/grade, learning support, privacy, and external-link controls.
4. Inspect the connected, read-only Google Classroom, calendar, district, and supply sources.
5. Preview the approved-only weekly digest.

## Boundaries judges should notice

- Homeroom never submits, grades, edits, posts, RSVPs, or changes a school source.
- AI proposals require explicit user action before any Homeroom-owned write.
- Student coaching stays private; guardians receive only Emily-approved notes and coarse progress evidence.
- School dates and supplies remain attributed to their official source; missing data is never invented.
- The public review household and source data are fictional.
